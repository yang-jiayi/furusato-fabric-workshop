# 24.2 操作手順

[Lab 目次](../README.md) · [この章の目次](README.md)

1. 初回は24.4で本人認証とフォルダー対応を確認し、24.5で配置計画を読み、自分の許可された範囲だけを書き込み承認します。
2. 24.6でソース、Notebook、Pipeline、Activator、主Ontologyを配置します。5〜8章は作成済みの内容を確認するために使い、同じものを追加しません。
3. 24.7と9〜10章で増分3ファイルを各1回取り込み、11章でNotebook05のプレビューと適用を実施します。24.8でモデルとAgentを作り、17章で調整済み構成、19章で回答を評価します。
4. 運用時は、データ更新、Graph更新、Metrics更新、Version history、回答再評価を別の作業として記録します。設定変更時は公開版を保存し、何を変えたかを記録します。
5. ワークショップ終了後の削除は、Activator停止と実行中Pipeline・Notebookが無いことを確認し、評価記録を保存してから行います。自分の参加者IDだけを、Data Agent→Power BIレポート（作成した場合）→Semantic model→主Ontologyと管理されたGraph→Activator→Pipeline→Eventhouse→Notebook→Lakehouseの順に削除します。削除が失敗したら繰り返さず、残る参照を確認します。

> 作業フォルダー、ワークスペース、容量、ロール、テナント設定、他人のアイテムを削除対象にしません。削除済みアイテムの完全消去は別の所有者確認が必要です。

## 24.2 Steps

1. On the first run, authenticate and verify folder mapping in 24.4, then review the concrete plan and authorize writes only in your permitted scope in 24.5.
2. Deploy sources, Notebooks, Pipeline, Activator and the main ontology in 24.6. Use Chapters 5–8 to inspect the created resources without adding duplicates.
3. Ingest each of the three increments once through 24.7 and Chapters 9–10, then preview and apply Notebook05 in Chapter 11. Create the model and Agent in 24.8, configure the adopted tuning in Chapter 17 and evaluate answers in Chapter 19.
4. In operation, record data updates, Graph refresh, Metrics refresh, Version history and answer reevaluation as separate activities. Save the current publication before changing settings and record each change.
5. For cleanup after the workshop, first stop Activator, confirm no Pipeline or Notebook is running and save evaluation records. Delete only your participant ID’s resources in this order: Data Agent → Power BI report if created → semantic model → main ontology and managed Graph → Activator → Pipeline → Eventhouse → Notebooks → Lakehouse. On failed deletion, inspect remaining references instead of retrying repeatedly.

> Do not delete the work folder, workspace, capacity, roles, tenant settings or others’ items. Permanent purging of deleted items requires separate owner review.
