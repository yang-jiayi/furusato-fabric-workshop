Download the matching [participant ZIP](Furusato_Workshop_v3.1.0_current.zip?raw=true) and verify [SHA-256](SHA256SUMS.txt).

The upstream icon terms are recorded in the [source notice](../../assets/architecture/upstream/NOTICE.txt); the original terms PDF is excluded from the participant package.

[HTML validation](DOCUMENT_VALIDATION.json) records static and browser checks for the exact HTML bytes. [Lab validation](LAB_VALIDATION.json) records source-text, image and link coverage. Evaluate your own publication with Chapter 19 and Appendix C using actual sources, queries and results.
