# 4.3 完了の確認

[Lab 目次](../README.md) · [この章の目次](README.md)

**この章の完了条件**

| 確認すること | うまくいかないとき |
| --- | --- |
| 自分の作業フォルダーと参加者IDを言える | 分からない場合は作業を始めず、講師に確認します。 |
| 必要な機能が表示され、権限エラーが出ない | 設定を変えずにその演習を止め、表示されない機能やエラーの内容を講師に伝えます。 |
| 作成したアイテムがすべて作業フォルダーにある | 別の場所にできた場合は、移動や削除をする前に講師に伝えます。 |

## 4.3 Check your work

**Completion checks for this chapter**

| What to check | If it does not work |
| --- | --- |
| You can state your work folder and participant ID | If you are unsure, do not start; ask the instructor. |
| The required features appear and no permission errors occur | Stop that lab without changing settings, and tell the instructor which feature is missing or which error appeared. |
| All the items you created are in your work folder | If an item was created elsewhere, tell the instructor before moving or deleting it. |
