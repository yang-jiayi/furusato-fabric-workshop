## 11.2 Steps

7. Confirm that quarantine.donation_events_rejected has 100 rows, and make sure that rejected rows were not silently dropped.
8. IsHighValue is an analysis flag for donations over JPY 57,000 (1,392 in Gold). It is neither a wealth classification nor a notification rule.

> Only when you run it automatically (for example through the Jobs API), set ALLOW_AUTOMATED_APPLY = True and EXPECTED_WORKSPACE_NAME before the preview. When you run it by hand in the portal, keep the defaults.

> The 14,900 rows in Gold come from the CSV files in Files/increment, a different input from the 15,000 Eventhouse rows. When comparing them, account for duplicates and quarantine.
