# 21.1 この章で行うこと

[Lab 目次](../README.md) · [この章の目次](README.md)

Version history を使うと、Ontology の定義に名前を付けて保存し、後で元に戻せます。戻せるのは定義（Entity・Relationship・バインドなど）で、元データ、アクセス権、Data Agent の設定は戻りません。

準備するもの・確認すること

- 主 Ontology を使います。講師が変更と復元を許可した場合だけ、説明を1つ変える演習を行います。読み取り専用の場合は版の一覧の確認だけにします。

## 21.1 What you will do

Version history lets you save the ontology definition under a name and restore it later. It restores the definition (entities, relationships, bindings and so on), not source data, access permissions or Data Agent settings.

Before you start

- Use the main ontology. Perform the single-description change and restore only if the instructor authorized both operations; with read-only access, inspect the version list only.
