# 20.1 この章で行うこと

[Lab 目次](../README.md) · [この章の目次](README.md)

Ontology の MCP エンドポイントを使うと、VS Code などの MCP クライアントから、Ontology の Entity と Rules の一覧を取得したり、照会したりできます。この章では、MCP の接続、ツールの確認、読み取り専用の照会を行い、可視化の方法も整理します。

MCP の利用には、有償の F2 以上または P1 以上の容量と、利用の権限が必要です。実際のエンドポイントの URL は自分の設定にだけ書き、共有する資料にはプレースホルダーを使います。

準備するもの・確認すること

- 講師が指定した MCP クライアントを用意します。
- 対象の Ontology の URL から、ワークスペースID とアイテムID を確認します（他の人と共有しません）。

## 20.1 What you will do

With the ontology MCP endpoint, MCP clients such as VS Code can list the ontology's entities and rules and run queries. In this chapter you connect over MCP, check the tools, run read-only queries and sort out the options for visualization.

MCP requires a paid F2 or higher, or P1 or higher, capacity and access permission. Keep the actual endpoint URL only in your own settings; use placeholders in anything you share.

Before you start

- Prepare the MCP client that the instructor specifies.
- Find the workspace ID and item ID in the URL of the target ontology (do not share them).
