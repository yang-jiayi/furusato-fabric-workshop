**この章の完了条件**

| 確認すること | うまくいかないとき |
| --- | --- |
| 同じに見える数字でも、粒度や対象が違えば別の値だと説明できる | 例：452025 の静的データの 1,813件と、8月の観測の 331件は別のデータです。一方を他方の一部として説明していないかを見直します。 |
| 根拠のない推論（発送、収入など）を、回答が断っている | 断っていない場合は、その質問と回答を、19章の改善の材料として記録します。 |
| UI の成功表示だけでなく、クエリの結果まで確認している | 作られた経路や、静的データと観測データの合算があれば、そこで止めて原因を記録します。 |

## 18.3 Check your work

**Completion checks for this chapter**

| What to check | If it does not work |
| --- | --- |
| You can explain why numbers that look alike are different values when their grain or scope differs | Example: the 1,813 static donations and the 331 August observations for 452025 are different data. Check that neither is described as part of the other. |
| The answers decline unsupported inferences (shipment, income and so on) | If they do not, record the question and answer as material for improvement in Chapter 19. |
| You checked not only success indicators in the UI but also the query results | If you find an invented path or static and observation data added together, stop there and record the cause. |
