# 19.1 この章で行うこと

[Lab 目次](../README.md) · [この章の目次](README.md)

Data Agent の回答品質を、付録Cの固定問題と条件で評価します。練習は T01〜T10を各1回（10回・84条件）、完全な公開評価は T01〜T10を各3回とB01〜B19を各1回（29種類・49回・290条件）です。各回を新しい会話で実施します。本章の追加手順で計画と記録ファイルを作り、同じ条件で再評価します。

採点では、数値の一致だけでなく、ソースの選び方、粒度の明示、安定した ID、境界の説明、断るべき質問への対応を同じ重みで見ます。改善するのは Agent の指示や例であり、質問や採点条件は変えません。

準備するもの・確認すること

- 17章の Data Agent の構成（指示、ソース、データ、Draft か公開版か）を固定し、日時とともに記録します。
- 付録Cの全問題と採点条件を開き、本章の追加手順で practice-10 または extended-public-49 の記録ファイルを用意します。
- 比較する質問、条件、構成、会話の初期化、送信回数、タイムアウト、採点方法を評価前に固定します。数値の内容確認と native クエリ実行の確認を別に採点し、未確認を成功に変えません。

## 19.1 What you will do

Evaluate Data Agent answers with the fixed questions and conditions in Appendix C. Practice runs T01–T10 once each (10 attempts, 84 conditions). The complete public evaluation runs T01–T10 three times each and B01–B19 once each (29 distinct questions, 49 attempts, 290 conditions). Start every attempt in a new conversation. Use this chapter's additional steps to create the plan and records and reevaluate under the same conditions.

Scoring looks not only at matching numbers but, with equal weight, at source choice, stated grain, stable IDs, explained boundaries and the handling of questions that should be declined. You improve the agent's instructions and examples, never the questions or the scoring conditions.

Before you start

- Freeze the configuration of the Data Agent from Chapter 17 (instructions, sources, data, Draft or published) and record it with the date and time.
- Open all questions and scoring conditions in Appendix C and prepare the practice-10 or extended-public-49 record files with this chapter’s additional steps.
- Freeze questions, conditions, configuration, conversation reset, submission count, timeout and review method before evaluation. Review answer content separately from actual native query execution; do not turn an unknown into success.
