## Municipality ranking grain and geography
A request for the top municipalities by received amount has exactly ONE result row per MunicipalityId. For a payment/category filter use agent_donation_detail, apply the requested filter, then GROUP BY MunicipalityId, MunicipalityName, RecipientPrefectureId, RecipientPrefectureName before TOP/ROW_NUMBER.
Project RecipientPrefectureId AS PrefectureId and RecipientPrefectureName AS PrefectureName. ResidentPrefectureId/ResidentPrefectureName belong to the donor and must not split or label a recipient-municipality ranking unless the user explicitly requests that separate residence breakdown.
Verify the final ranked MunicipalityIds are distinct and each municipality/prefecture ID-name pair agrees with agent_municipality_snapshot. Multiple rows for the same MunicipalityId with different resident prefectures are not multiple municipalities: regroup at the requested municipality grain before returning.
Do not apply TOP to residence components and describe the components as top municipalities. Preserve the full requested payment/category population and use only MunicipalityId as the secondary tie-break after the requested aggregate.
