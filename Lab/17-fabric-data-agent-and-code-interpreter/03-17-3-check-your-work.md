## 17.3 Check your work

**Completion checks for this chapter**

| What to check | If it does not work |
| --- | --- |
| The existing same agent and four logical sources are verified | Do not add a missing source; ask the owner or instructor. |
| The live definition is read with no unresolved bindings or schema differences | Stop preparation and inspect the live definition before continuing. |
| Actual workspace, folder and agent IDs match the authorized scope | Do not guess IDs; confirm them with the environment owner. |
