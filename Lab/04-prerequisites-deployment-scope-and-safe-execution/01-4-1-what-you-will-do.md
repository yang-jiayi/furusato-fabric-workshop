# 4.1 この章で行うこと

[Lab 目次](../README.md) · [この章の目次](README.md)

演習を始める前に、作業する場所、使える機能、自分の権限を確認します。ここで確認した範囲の外では作業しません。

この演習には、利用可能な Fabric 容量、アイテムの作成・編集、データソースの読取とモデルのBuild、Gen2 Ontology と Data Agent の利用条件が必要です。テナント設定は管理者に確認します。必須のソースやAgentが使えない場合は、その後の依存する作業を完了扱いにしません。Graph、Metrics、時系列などの個別プレビュー機能が未対応の場合は、その項目を未達として別に記録し、利用できるSQL・KQL・DAXの評価と区別します。

準備するもの・確認すること

- 講習では割り当てられたワークスペース、作業フォルダー、参加者IDを使います。自習では、自分が作成・編集を許可されたワークスペースで空の作業フォルダーを用意し、他のアイテムと重ならない001〜999の参加者IDを選びます。権限や容量が不足する場合はワークスペース管理者へ依頼します。
- ZIP の source/workshop/v3.0.0-preview 一式と source/tools を用意します。フォルダー割当や権限の確認後、初回は24.4〜24.6の手順で参加者自身が配置します。

## 4.1 What you will do

Before starting the labs, confirm where you work, which features are available and what permissions you have. Do not work outside the scope you confirm here.

This lab requires available Fabric capacity, permission to create/edit items, read data sources and Build the model, and support for Gen2 Ontology and Data Agent. Confirm tenant prerequisites with the administrator. If a required source or Agent is unavailable, do not mark dependent work complete. Record unsupported individual preview features such as Graph, Metrics or time series as unmet, separately from available SQL, KQL and DAX evaluation.

Before you start

- For a class, use the assigned workspace, folder and participant ID. For self-study, prepare an empty folder in a workspace where you are authorized to create/edit resources and choose an unused participant ID from 001 to 999. Ask the workspace administrator to resolve missing access or capacity.
- Have the ZIP’s complete source/workshop/v3.0.0-preview and source/tools directories available. After confirming folder assignment and access, perform the first deployment yourself using 24.4–24.6.
