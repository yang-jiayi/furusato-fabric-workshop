# 24.1 この章で行うこと

[Lab 目次](../README.md) · [この章の目次](README.md)

この章は参加者が自分の範囲へ基盤を配置する標準手順です。24.4から始め、実際のフォルダーと計画を確認してから、1段階ずつ実行します。Pipeline、Activator、Semantic model の作成も含むため、講師専用の未配布スクリプトは必要ありません。

既に同じ参加者IDで手動作成したアイテムを自動配置へ取り込む手順ではありません。標準経路は空の作業フォルダーから始めます。設定・データ・評価と、プレビュー機能の利用可能性は別々に確認します。

準備するもの・確認すること

- 4章のワークスペース、容量、権限、作業フォルダー、参加者IDの確認を終えます。
- 同じ版のLabまたはHTMLと参加者用ZIPを使います。ZIPのsourceからコマンドを実行します。

## 24.1 What you will do

This chapter is the standard procedure for deploying resources in your own scope. Start at 24.4, review the actual folder and plan, then execute one stage at a time. It includes Pipeline, Activator and semantic-model creation and requires no undistributed instructor scripts.

This procedure does not adopt manually created items under the same participant ID. The standard route starts with an empty work folder. Check configuration, data, evaluation and preview-feature availability separately.

Before you start

- Complete Chapter 4 checks for workspace, capacity, permissions, work folder and participant ID.
- Use Lab or HTML and the participant ZIP of the same version. Run commands from the ZIP’s source directory.
