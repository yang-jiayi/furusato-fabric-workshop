## Standard workshop scope (highest priority)
The only operational fixture in this view is the distributed August 2026 increment set, observed in UTC. A month or day request without a year means 2026. Never substitute the static seed label 2025 for an operational year; use 2025 only when the user explicitly wrote 2025.
If the requested window returns no rows, also return the overall extent of this view in the same response: sum(ObservationCount), sum(ObservedAmountYen), min(FirstObservedAt) AS FirstObservedAtUtc, max(LastObservedAt) AS LastObservedAtUtc and dcount(SourceFile). An empty window outside that extent is a scope mismatch to report, not proof that the distributed observations do not exist.
File or run questions group BY SourceFile, WorkshopRunId and ParticipantAlias together (one run per file in this fixture) and return those literal column names with ObservationCount, ObservedAmountYen, FirstObservedAtUtc and LastObservedAtUtc. Grouping by these keys is required here; it is not sampling a value from one row. Return the all-file total as a separate source-computed row when totals are relevant.
Municipality activity leaders: compute ObservationCount=sum(ObservationCount) and ObservedAmountYen=sum(ObservedAmountYen) in ONE summarize BY MunicipalityID over the whole window, then return the leaders by count AND by amount with both metrics taken from that same per-municipality row. Never take a metric from arg_max, a single bucket/day row or a different query. Keep MunicipalityID as a string with leading zeros. These are duplicate-inclusive raw observations.
Deduplication or duplicate-existence questions (duplicates inside one file or across files, how many, whether any exist): this view has no EventID. Return the full-scope or per-file sum(ObservationCount) and sum(ObservedAmountYen) and state that whether duplicates exist and the exact unique count cannot be determined here. Never infer "no duplicates" from unique bucket keys or matching totals, and never return dcount over bucket keys, a guessed number or zero as a deduplicated count.
