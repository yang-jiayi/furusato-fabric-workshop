2. クライアントが表示する通常のサインイン（OAuth）の画面で認証します。トークンを取り出したり共有したり、セキュリティの設定を無効にしたりしません。
3. ツールの一覧を確認し、ask_ontology、list_ontology_rules、list_ontology_entities の3つがあることを確かめます。一覧に無いツール名を呼び出しません。
4. list_ontology_entities と list_ontology_rules を呼び出し、Entity type と Rules が Ontology の画面と一致することを確認します（主 Ontology なら10の Entity type と、登録した Rules）。
5. ask_ontology で、件数を限った読み取り専用の質問をし、同じ条件の SQL・KQL・DAX の結果と比べます。別の Ontology やモデルに接続していないかも確認します。

**Readable prompt — 日本語**

<div>
SupplierProvidesGift の関係を最大20件、SupplierId と GiftId で返してください。使ったクエリも示してください。
</div>

**Verbatim prompt follows.**

```text
SupplierProvidesGift の関係を最大20件、SupplierId と GiftId で返してください。使ったクエリも示してください。
```

6. 現在の仕様では、ask_ontology は回答に Rules を使いません。Rules を読み取れることと、照会の回答に Rules が反映されることは、別々に確認します。
7. （任意）公開済みの Data Agent も MCP で使えます。Data Agent の Settings → Model Context Protocol でエンドポイントを確認します。形式は次のとおりです。公開前の Agent や、Ontology のエンドポイントで代用しません。

**Readable wrapped view — URL**

<div>
https://api.fabric.microsoft.com/v1/mcp/workspaces/&lt;WORKSPACE_ID&gt;/dataagents/&lt;DATA_AGENT_ID&gt;/agent
</div>

**Verbatim source follows; copy from the canonical block.**

**URL**

```text
https://api.fabric.microsoft.com/v1/mcp/workspaces/<WORKSPACE_ID>/dataagents/<DATA_AGENT_ID>/agent
```

8. （任意）Data Agent に Sources → Add sources → Add an ontology が表示される場合は、Ontology を文脈として追加し、Download ontology context で内容を確認できます。文脈の変更の反映には最大10分かかります。No data added のままの場合は、設定を変えずに講師に伝えます。
9. Real-Time Dashboard に Ontology を直接つなぐ機能は、画面に表示される場合だけ試します。表示されない場合はこの手順を省略し、手作業で作った CSV やグラフを「直接の連携」として扱いません。

> エンドポイントの URL、ワークスペースID、アイテムID は資格情報と同じように扱い、画面共有や資料に含めません。

## 20.2 Steps

1. In the MCP client, configure an HTTP MCP server with an endpoint in the following format. Replace &lt;WORKSPACE_ID&gt; and &lt;ONTOLOGY_ID&gt; with your own values.

**Readable wrapped view — URL**

<div>
https://api.fabric.microsoft.com/v1/mcp/dataPlane/workspaces/&lt;WORKSPACE_ID&gt;/items/&lt;ONTOLOGY_ID&gt;/ontologyEndpoint
</div>

**Verbatim source follows; copy from the canonical block.**

**URL**

```text
https://api.fabric.microsoft.com/v1/mcp/dataPlane/workspaces/<WORKSPACE_ID>/items/<ONTOLOGY_ID>/ontologyEndpoint
```

2. Authenticate through the normal sign-in (OAuth) screen that the client shows. Never extract or share tokens or disable security settings.
3. Check the list of tools and confirm that ask_ontology, list_ontology_rules and list_ontology_entities are present. Never call a tool name that is not in the list.
4. Call list_ontology_entities and list_ontology_rules and confirm that the entity types and rules match what the ontology shows (for the main ontology, 10 entity types and the rules you registered).
5. Use ask_ontology for a read-only question with a limited number of rows, and compare the result with SQL, KQL or DAX under the same conditions. Also check that you are not connected to a different ontology or model.

**Readable prompt — English**

<div>
Return up to 20 SupplierProvidesGift links as SupplierId and GiftId. Also show the query you used.
</div>

**Verbatim prompt follows.**

```text
Return up to 20 SupplierProvidesGift links as SupplierId and GiftId. Also show the query you used.
```

6. With the current product behavior, ask_ontology does not use Rules in its answers. Check separately that Rules can be read and whether they are reflected in query answers.
7. (Optional) A published Data Agent can also be used over MCP. Find its endpoint under Settings → Model Context Protocol in the Data Agent. The format is as follows. Do not use an unpublished agent or the ontology endpoint instead.

**Readable wrapped view — URL**

<div>
https://api.fabric.microsoft.com/v1/mcp/workspaces/&lt;WORKSPACE_ID&gt;/dataagents/&lt;DATA_AGENT_ID&gt;/agent
</div>

**Verbatim source follows; copy from the canonical block.**

**URL**

```text
https://api.fabric.microsoft.com/v1/mcp/workspaces/<WORKSPACE_ID>/dataagents/<DATA_AGENT_ID>/agent
```

8. (Optional) If Sources → Add sources → Add an ontology appears in the Data Agent, you can add an ontology as context and check it with Download ontology context. Context changes can take up to 10 minutes to apply. If it stays at No data added, tell the instructor without changing settings.
9. Try connecting an ontology directly to a Real-Time Dashboard only if the feature appears on screen. If it does not, skip this step, and do not treat manually made CSV files or charts as a direct integration.

> Treat endpoint URLs, workspace IDs and item IDs like credentials; keep them out of screen shares and documents.
