## D.1 List

These are additional exercises you can try after the required labs, depending on your time and environment. Skip any feature that does not appear on screen.

**Optional exercises**

| Name | What it is |
| --- | --- |
| Power BI report | Show the distributed Furusato_Analytics.Report connected to the existing semantic model (deployed by the instructor). Check the displayed totals against DAX (Gold 94,900 rows / JPY 1,596,157,000; 1,392 high-value donations). Chapter 12 gives the optional checks for an already deployed report. |
| Ontology as Data Agent context | If Sources → Add sources → Add an ontology appears, add an ontology as context and check it with Download ontology context (Chapter 20). |
| Data Agent over MCP | Use a published Data Agent from an external MCP client through the endpoint under Settings → Model Context Protocol (Chapter 20). |
| Direct Real-Time Dashboard integration | Try it only if the feature for connecting an ontology directly to a Real-Time Dashboard appears (Chapter 20). |
| Namespaces | Try the namespace steps in Chapter 14 only if + Namespace or Manage namespaces appears. |
| High-value donation analysis | Analyze with IsHighValue in Gold (donations over JPY 57,000) and the measure 高額寄附件数. Do not use them to judge wealth or to send notifications. |
| Test the ontology in the Ontology agent | Try the five questions offered after an ontology is first published. Do not use them for scoring in Chapter 19. |
