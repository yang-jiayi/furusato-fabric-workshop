## 11.2 Steps

8. Only if quarantine.donation_events_rejected is actually readable from the target endpoint or an authorized run output, record its count and rejection reasons. If it cannot be read because the table is missing, unsynchronized or blocked by permissions, mark it unverified and do not claim 100 as an observed count. Do not change permissions; tell the instructor.
9. IsHighValue is an analysis flag for donations over JPY 57,000, not a wealth classification or notification rule. Record its Gold count only if Gold data can actually be queried.

> Only when you run it automatically (for example through the Jobs API), set ALLOW_AUTOMATED_APPLY = True and EXPECTED_WORKSPACE_NAME before the preview. When you run it by hand in the portal, keep the defaults.

> 14,900 accepted increments is the expected result when Notebook 05 processes complete, verified CSVs in Files/increment. It is a different population from the 15,000 Eventhouse KQL observations. Check your own run output before recording observed values.
