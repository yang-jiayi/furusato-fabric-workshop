# Static-first instruction candidate

This is a portable, general semantic-instruction addendum, not a replacement
for the main profile or a set of question-specific answers. It contains no live
item identities, evaluation answer keys or observed result values.

For the bounded experiment, append it to a separately created candidate's copy
of the current published GLOBAL instructions. Preserve the original four source
definitions, selected schema elements, source instructions and Code Interpreter
settings. Do not apply it to the main agent automatically.

The intervention makes the static snapshot the explicit default, retains both
readings of geographic metrics, requires scoped popularity measures and stable
IDs, refuses raw/static composition, and excludes unsupported income or wealth
inferences. Existing safety and execution-evidence guards remain in force.

Freeze the candidate before evaluation. Configuration publication only enables
the separate candidate endpoint; it is not quality acceptance or promotion.
Keep live IDs, request/response evidence, grades and comparison results outside
the public source tree. A better result on known regression questions does not
establish general accuracy, source execution proof or readiness of blocked
Graph/raw-data scenarios.
