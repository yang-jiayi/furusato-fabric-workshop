## 11.2 Steps

8. Only if quarantine.donation_events_rejected is actually readable from an authorized run output, record its count and rejection reasons. If it is unavailable in the current SQL catalog, mark it unverified and do not claim 100 as an observed count.
9. IsHighValue is an analysis flag for donations over JPY 57,000, not a wealth classification or notification rule. Record its Gold count only if Gold data can actually be queried.

> Only when you run it automatically (for example through the Jobs API), set ALLOW_AUTOMATED_APPLY = True and EXPECTED_WORKSPACE_NAME before the preview. When you run it by hand in the portal, keep the defaults.

> 14,900 accepted increments is an expectation when Notebook 05 processes verified-complete Files/increment CSVs. It is a different population from the 15,000 Eventhouse KQL observations; do not report it as an observed Gold result without run evidence.
