# 17.3 操作手順

[Lab 目次](../README.md) · [この章の目次](README.md)

1. Add data / Sources で既存の Lakehouse、KQL Database、Semantic model、主 Ontology を確認します。4つの論理ソースと物理 datasource レコード数を取り違えず、ソースを追加しません。
2. Data Agent の Tools で Code Interpreter の状態を記録します。この章の profile 適用を回避するため、別の Agent や Tool を作成しません。
3. 既存 definition、source selections、Ontology context、各 stage を先に読み取ります。期待する selection との意味差分、schema drift、native type drift、曖昧な binding を見つけたら停止します。

## 17.3 Steps

1. In Add data / Sources, confirm the existing Lakehouse, KQL Database, semantic model and main Ontology. Do not confuse four logical sources with physical datasource record count, and do not add sources.
2. Record the Code Interpreter state under Data Agent Tools. Do not create another agent or tool as a workaround for applying this profile.
3. Read the existing definition, source selections, Ontology context and stages first. Stop on semantic differences from the expected selections, schema drift, native type drift or ambiguous bindings.
