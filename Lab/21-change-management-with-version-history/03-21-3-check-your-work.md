# 21.3 完了の確認

[Lab 目次](../README.md) · [この章の目次](README.md)

**この章の完了条件**

| 確認すること | うまくいかないとき |
| --- | --- |
| + New Version で保存した版が一覧に表示される | 表示されない（No versions yet のまま）場合は、同じ保存を繰り返さず、Restore の演習は行わずに講師に伝えます。 |
| 保存した時点の定義に戻り、今の作業も版として残っている | 戻っていない場合は、選んだ版が正しいかを確認します。Restore を何度も繰り返しません。 |
| Metrics を含む Ontology を戻した場合も、Metrics が元のとおり | 各 Metric の Source と、View expression の式が戻す前と同じかを確認し、同じ条件で DAX の結果も比べます。 |

## 21.3 Check your work

**Completion checks for this chapter**

| What to check | If it does not work |
| --- | --- |
| The version saved with + New Version appears in the list | If it does not (the list still shows No versions yet), do not repeat the save; skip the Restore exercise and tell the instructor. |
| The definition is back to the saved point, and your current work is kept as a version | If it was not restored, check that you chose the right version. Do not repeat Restore over and over. |
| If you restored an ontology with Metrics, the Metrics are as before | Check that each metric's Source and the expression shown by View expression are the same as before, and compare DAX results under the same conditions. |
