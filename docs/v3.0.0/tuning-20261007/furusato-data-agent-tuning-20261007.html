実装した改善 / Implemented changes

time-layer-isolationまでの修正チェーンが元の統合指示を置き換え、標準10問の回答契約が失われていました。standard-contract-restorationを4つ目のAgent compilerとして追加し、最優先の全体契約と4ソースの契約を既存指示の先頭へ置きました。

年の指定がない「8月」、流入・観測・イベント・ファイル・増分は2026年8月UTCの生観測と定義しました。2025は静的seedの年ラベルで、明記された時だけ使います。0件や矛盾がある場合は全体期間を確認してから結論します。

複合質問は観測（Eventhouse・重複込み）、静的値と全国順位（Lakehouse）、所属県（Ontology）を分担し、MunicipalityIdで突き合わせ、足し合わせません。

受入/在住の両方の読み方、人気＝件数と金額・ID・全国スコープ、Ontologyの所属COUNTとliteral行、寄付追跡の全IDとカタログ登録・履行の境界、ファイル/実行の見出し、EventIDがないため重複除外件数を出さない契約を復元しました。

静的と観測の合算依頼は固定の回答形式で拒否し、利用者が示した合計値を書きません。比較は差・倍率・増減率の3行で示し、要約で言い換えません。数値は「約」や万・億へ換算しません。

生成クエリの脆弱性に対処しました。KQLの上位自治体は1回のsummarizeから両指標を取り、Ontologyは接尾辞付きの日本語名で照合して0件なら再試行し、MunicipalityIdは文字列として扱います。

例はKQL1件を置換し5件を追加しました（SQL17・KQL9）。全26例を実ソースで実行し、行を返すことを確認しました。ソースID・選択・Published部分・データ・メジャーは変更していません。

The corrected profile chain had replaced the original unified instructions and lost the standard-question contracts. A fourth Agent compiler, standard-contract-restoration, prepends a highest-priority coordinator contract and four source contracts.

It restores the year-less August 2026 default, three-source composite routing, both prefecture readings, popularity on both metrics, Ontology membership COUNT, the complete donation trace, fixed refusal/comparison forms, numeric fidelity and robust generated-query rules. Source identities, selections, Published parts, data and measures are unchanged.
