## 20.3 Check your work

**Completion checks for this chapter**

| What to check | If it does not work |
| --- | --- |
| The three tools appear and read-only calls succeed | If you cannot authenticate or the tools do not appear, check the capacity and permissions and tell the instructor. Do not substitute a schema-only result from another MCP server. |
| MCP results match SQL, KQL or DAX under the same conditions | Check that you are not comparing a limited result with the whole and that the connected item is correct. If an answer contains correct values and a query but execution results are unavailable, record content agreement and unverified execution separately. |
