## Standard workshop scope (highest priority)
The only operational fixture in this view is the distributed August 2026 increment set, observed in UTC. A month or day request without a year means 2026. Never substitute the static seed label 2025 for an operational year; use 2025 only when the user explicitly wrote 2025.
If the requested window returns no rows, also return the overall extent of this view in the same response: sum(ObservationCount), sum(ObservedAmountYen), min(FirstObservedAt) AS FirstObservedAtUtc, max(LastObservedAt) AS LastObservedAtUtc and dcount(SourceFile). An empty window outside that extent is a scope mismatch to report, not proof that the distributed observations do not exist.
File or run questions group BY SourceFile, WorkshopRunId and ParticipantAlias together (one run per file in this fixture) and return those literal column names with ObservationCount, ObservedAmountYen, FirstObservedAtUtc and LastObservedAtUtc. Grouping by these keys is required here; it is not sampling a value from one row. Return the all-file total as a separate source-computed row when totals are relevant.
Municipality activity leaders: compute ObservationCount=sum(ObservationCount) and ObservedAmountYen=sum(ObservedAmountYen) in ONE summarize BY MunicipalityID over the whole window, then return the leaders by count AND by amount with both metrics taken from that same per-municipality row. Never take a metric from arg_max, a single bucket/day row or a different query. Keep MunicipalityID as a string with leading zeros. These are duplicate-inclusive raw observations.
Deduplication or duplicate-existence questions (duplicates inside one file or across files, how many, whether any exist): this view has no EventID. Return the full-scope or per-file sum(ObservationCount) and sum(ObservedAmountYen) and state that whether duplicates exist and the exact unique count cannot be determined here. Never infer "no duplicates" from unique bucket keys or matching totals, and never return dcount over bucket keys, a guessed number or zero as a deduplicated count.

## Source meaning
DonationObservationSummaryForAgent contains raw, duplicate-inclusive observations. Its exact row key is MunicipalityID + EventMinute + WorkshopRunId + ParticipantAlias + SourceFile. Its remaining columns are ObservationCount, ObservedAmountYen, FirstObservedAt, LastObservedAt, LastPublishedAtUtc. There is NO donor, gift, supplier, EventID, DataSource or processing-status field.

## Query plan
Filter EventMinute with the requested half-open absolute UTC interval. The distributed August2026 fixture label uses UTC unless the user explicitly requests a JST day/month. Convert JST boundaries to UTC.
SUM(ObservationCount) and SUM(ObservedAmountYen) provide observations and money. COUNT counts aggregated buckets, NOT observations or unique events.
Always project min(FirstObservedAt) AS FirstObservedAtUtc and max(LastObservedAt) AS LastObservedAtUtc for each output group. These are observed DonatedAt extrema, not the requested interval boundaries.
Group only by the requested time/file/municipality grain. For day/hour totals, aggregate across ALL files; "each file once" is the ingestion premise, not a request to group by file. Display every requested day/hour, not a sample. Check missing days against the full calendar.
For bucket-versus-observation questions, return BucketRows=count(), ObservationCount=sum(ObservationCount), ObservedAmountYen=sum(ObservedAmountYen), both extrema, and the exact five-field grain. Do not add donor identity.
Return those all-file totals as ONE source-computed summary row when the user asks for the overall comparison. "Each CSV once" is not a request for optional file tables. Do not manually add file totals in the answer or rescale yen values. If both total and components are explicitly requested, compute both in the source and preserve the exact integer results; check their equality before responding.
For file publication questions, use max(LastPublishedAtUtc) AS SyntheticCsvPublishedAtUtc. This is a synthetic PublishedAtUtc value supplied IN THE CSV, not actual Eventhouse publication, ingestion, upload or pipeline telemetry. Include file, count, money and both DonatedAt extrema. State "CSVに用意された合成の配信時刻。実際の取込・公開・処理完了時刻ではない。"
Preserve actual requested SourceFile/WorkshopRunId/ParticipantAlias strings. Raw totals are not accepted or deduplicated totals. EventID is absent, so exact deduplication cannot be established from this view.
