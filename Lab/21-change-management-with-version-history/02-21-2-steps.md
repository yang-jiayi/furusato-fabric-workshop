# 21.2 操作手順

[Lab 目次](../README.md) · [この章の目次](README.md)

1. 画面右上の Version history を開き、+ New Version を選びます。Version name（例：before-description-change、100文字以内）と Description（500文字以内）を入力して保存します。空白だけの名前は使いません。
2. 保存した版が一覧に表示され、時刻と作成者が記録されていることを確認します。
3. 許可された場合は、SupplierProvidesGift の説明（Metadata の Edit）だけを変更して保存します。データ、キー、バインドは変えません。変更後の説明と元データの件数を記録します。
4. Version history で、手順1で保存した版の … から Restore を選びます。確認画面で Create a version of my current work first を選び、表示された Version name と Description を入力して、Restore を選びます。
5. 開き直して、説明が元に戻っていること、Entity・Relationship・バインドが変わっていないことを確認します。今の作業を保存した版が一覧にあることも確認します。
6. 元データの件数や値が変わっていないことを、Instances や SQL で別に確認します。

> Restore は定義全体を置き換えます。版の削除は元に戻せないため、この演習では削除しません。

> 大きな変更を行う別の作業では、適用前に版を保存します。15章の標準演習は Plan の読み取りだけです。

## 21.2 Steps

1. Open Version history at the top right and select + New Version. Enter a Version name (for example before-description-change, up to 100 characters) and a Description (up to 500 characters), then save. Do not use a name made only of spaces.
2. Confirm that the saved version appears in the list with its time and creator.
3. When authorized, change and save only the description of SupplierProvidesGift (Edit under Metadata). Keep data, keys and bindings unchanged, and record the new description and source data counts.
4. In Version history, select Restore from … on the version saved in step 1. In the confirmation dialog, select Create a version of my current work first, enter the Version name and Description that appear, and select Restore.
5. Reopen the ontology and confirm that the description is back to the original and that entities, relationships and bindings are unchanged. Also confirm that the version saving your current work is in the list.
6. Separately confirm with Instances or SQL that the source data counts and values did not change.

> Restore replaces the whole definition. Deleting a version cannot be undone, so do not delete versions in this lab.

> For separate work that makes major changes, save a version before applying them. The standard exercise in Chapter 15 is read-only Plan.
