# 23.3 完了の確認

[Lab 目次](../README.md) · [この章の目次](README.md)

**この章の完了条件**

| 確認すること | うまくいかないとき |
| --- | --- |
| 公開した対象、利用者、許可した範囲、残っている課題を説明できる | 説明できない項目がある場合は、公開を止めて講師に確認します。 |
| 共有した相手が、許可した範囲のデータだけを読める | Read 権限を付けたことだけで判断せず、元データの権限を確認します。 |

## 23.3 Check your work

**Completion checks for this chapter**

| What to check | If it does not work |
| --- | --- |
| You can state what was published, for whom, the permitted scope and the remaining issues | If you cannot explain an item, stop publishing and ask the instructor. |
| The people you shared with can read only the data you allowed | Do not rely on having granted Read alone; check the permissions on the source data. |
